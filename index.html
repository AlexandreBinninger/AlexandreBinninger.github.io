What I'm building

I'm building Boldbobbin, the modern platform for embroidery design. It's the kind of tool I wished existed when I first started using embroidery machines: clean, fast, intuitive, yet powerful, reasonably priced, and built for the way people actually create patterns. Just because embroidery is a legacy art doesn't mean it needs to be designed on legacy software.

My bet is that the next generation of embroidery software should look much more like the creative tools we expect everywhere else: web-first, collaborative, with powerful digitizing tools built in. That's my goal with Boldbobbin, and I'm working on it full-time.

You can try it at boldbobbin.com.
